## Machine Learning / Deep Learning

Built upon exploratory analysis, these projects focus on building all-inclusive machine learning pipelines, with an emphasis on real-world data, robust evaluation, and model generalization.

<div class="features">
    <article>
        <a target="_blank" href="https://www.kaggle.com/code/cresht2606/vietnam-real-estate-catalyst-project-eda" class="image">
            <img src="/images/vietnam_real_estate.jpg" alt="Vietnam Real Estate - Codename: Azeroth" />
        </a>
        <div class="inner">
            <h4>Vietnam Real Estate - Codename: Azeroth</h4>
            <i><b>Date Originated: Sep 19th, 2025</b></i>
            <p>A house price prediction project using Vietnam real estate data collected from BatDongSan.vn. The whole process involves data scraping, preprocessing, feature engineering, and exploratory analysis to capture insightful market patterns.</p>
            <p>Trained and evaluated multiple regression and gradient boosting models (LightGBM, XGBoost, CatBoost) with cross-validation and leakage control. A stacked ensemble achieved human-capable performance (RMSE ≈ 0.783, R² ≈ 0.47), indicating decent generalization improvements across diverse property segments. Additionally, EDA section was briefly introduced via Streamlit.</p>
